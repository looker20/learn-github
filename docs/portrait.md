- Portrait 800 × 1000 pixels, JPEG de 107 272 octets, sans métadonnées EXIF.
- La photographie originale reste en dehors du dépôt. Seule la version retouchée autorisée est publiée.
- Retouche réalisée avec l’outil intégré **imagegen**, puis encodage JPEG optimisé pour le web. Aucun appel API par CLI, aucune clé API ajoutée au projet.
- Fond, cadrage, éclairage et tenue retouchés ; conservation de l’identité et des lunettes demandée explicitement. Le résultat est une image retouchée, pas une photographie de studio originale.
